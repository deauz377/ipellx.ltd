Accessibility Features

✓ WCAG AA Compliant

All color combinations meet minimum contrast ratios:

  • 4.5:1 for normal text on colored backgrounds
  • 3:1 for large text and UI components
  • 7:1+ for semantic status colors
✓ Not Color-Dependent

Information is conveyed through multiple methods (color + icons + text + patterns)

✓ User Preferences Respected

Supports prefers-reduced-motion, prefers-contrast, and prefers-color-scheme
